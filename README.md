**I. Introduce:** Saucedemo Checkout Test Suite

- This project is an automated test suite for the Saucedemo checkout process using Selenium WebDriver and Cucumber. 

**II. Technologies Used**

- Java 17

- Maven

- Selenium WebDriver

- Cucumber (BDD framework)

- JUnit

**III. WebDriverManager**

1️. Prerequisites

- Make sure you have the following installed:

- Java 17 or higher

- Maven

- Chrome browser ("134.0.6998.89")

2️. Clone the Repository

- git clone https://github.com/your-repo/saucedemo-test.git

- cd saucedemo-test

3️. Install Dependencies

- mvn clean install

4️. Run the Tests

- mvn test

**IV. Configurations**

- Ensure that the correct ChromeDriver version is used in WebDriverManager.

- Modify the chromeOptions if necessary to match your system configuration.
 
**V. Reporting**

- After running tests, the results can be found in: target/cucumber-reports/index.html

- Open this file in a browser to view the test report.
